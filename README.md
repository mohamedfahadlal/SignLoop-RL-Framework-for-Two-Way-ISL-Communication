
# SignLoop: RL Framework for Two-Way ISL Communication

This repository contains the Reinforcement Learning framework for two-way Indian Sign Language (ISL) translation. 

Currently, we are in **Stage 1: Data Preprocessing**. This guide explains how to set up the environment and run the offline preprocessing scripts to turn raw video files from the INCLUDE dataset into normalized 3D spatiotemporal tensors for our Gymnasium environment.





---

## Folder Structure

To ensure Git doesn't track our massive video files and `.npz` outputs, everyone must use this exact folder structure. The `dataset` folder is ignored by `.gitignore`.

```text

├── .gitignore
├── requirements.txt

├── data_prep.py

```
##  Environment Setup

CRITICAL: You must use Python 3.12 (or 3.11). Python 3.13 is currently incompatible with the required version of Google MediaPipe.

### 1. Clone the Repository

```Bash
git clone <your-github-repo-url>
cd SignLoop-RL-Framework-for-Two-Way-ISL-Communication
```

## 2. Create the Virtual Environment
Open your terminal (Command Prompt) and create an isolated sandbox named `isl_venv`

```DOS
py -3.12 -m venv isl_venv
```

### 3. Activate the Environment
You must see (isl_venv) at the start of your command prompt before proceeding.
Windows:

```DOS
isl_venv\Scripts\activate
```

### 4. Install Dependencies
Install the strictly version-controlled packages from the requirements file. (Note: MediaPipe is locked to 0.10.14 to retain the legacy solutions API).

```DOS
pip install -r requirements.txt
```
