# 3D Models Directory

This directory stores rigged 3D humanoids and avatar components.

## Requirements
* **Rig Type:** Humanoid armature with 21-joint finger chains per hand (thumb, index, middle, ring, pinky).
* **Blendshapes:** 52 ARKit/FACS facial blendshapes for Non-Manual Markers (NMMs) (e.g. brow, eye, jaw, mouth shapes).
* **Git LFS:** All `.fbx`, `.obj`, `.blend`, `.glb`, `.gltf` files are tracked via Git LFS. Ensure `git lfs install` is active before committing large assets.
